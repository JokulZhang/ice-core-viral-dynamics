# Ice-core viral dynamics

Code archive for the study **“Seven decades of ice-core viral dynamics reveal warming-driven shifts from natural to anthropogenic inputs.”**

## Status

This repository currently contains a directory structure only. Analysis code, input data, results, and reproduction instructions have not yet been added.

## Structure

- `scripts/`: analysis scripts.
- `config/`: configuration files.
- `metadata/`: sample and input metadata.
- `docs/`: additional documentation.

## Reproducing the analysis

When the code is added, document input data and access, software and package versions, configuration, and execution steps here or in `docs/`.

## Citation and archiving

The paper citation and code archive DOI will be added when available. Before release, choose a license and review the repository contents. To archive a release, make the repository public, enable it in the [Zenodo GitHub integration](https://zenodo.org/account/settings/github/), and create a GitHub release. Cite the DOI for the archived version.
